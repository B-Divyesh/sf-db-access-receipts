Privacy for local receipts

DB Access Receipts runs locally. The CLI has no telemetry.

What stays on your device

Receipt JSON is written only to the directory in your policy. Receipts omit result cells, raw SQL, database URLs, and raw parameter values by default.

The CLI asks your operating system keychain to store database URLs and signing keys. It fails instead of writing a plaintext secret when the keychain is unavailable.

Browser storage

The home preview stores local receipts under db-receipts:receipts. The demo uses only demo:db-receipts:receipts. Each route stores its own optional theme choice.

Use Clear local history, Clear demo history, Reset demo, or browser storage settings to remove this data.

Network activity

This site uses no analytics, advertising, third-party fonts, payment forms, or tracking scripts. Same-origin files may be cached for offline use.

Your control

Remove CLI secrets with db-receipts secret clear. Delete receipt files with your normal retention process.

Contact

For privacy questions, open an issue in the project repository. Do not include credentials, query text, or database data.
