    How it works

    Check every SQLite read

    One local binary checks policy before it opens the database.

    1. Choose a named template

      Templates declare their parameters and row and column limits.

    2. Ask for human approval

      Novel SQL needs an attached terminal and a one-use challenge.

    3. Keep a signed receipt

      Allowed, denied, and failed attempts can be verified without database access.

    db-receipts query --template open-orders --param account_id=acct_123 --actor analyst@team

db-receipts verify .db-receipts/receipts/receipt.json

    Limits and privacy

    What this tool does not do

    It supports file-backed SQLite only. It does not generate SQL, manage credentials, or replace database permissions.

    Receipts omit result data, raw SQL, database paths, and raw parameter values. The CLI has no telemetry.

    Read the privacy policy and read the terms.
